## Unresolved state and capability obligations

1. Query launch confidence must be captured or reconstructed before any stall can lose its version. A fixed small log is insufficient without a bounded capture delay. The simple late Context-read counterexample is recorded in counterexample-review.md; that rejected timing is not an accepted capability here.
2. Source has four abstract stage slots, Hint modifies index2 and later, and first matching stage determines override bubbles before FTQ admission. kmhv2 has three physical stages. The source loop's0–3 range is only a syntactic bound; prove actual relevant stage equality and observation alignment instead of assuming a fixed two-cycle path.
3. FTQ64, one pending prediction, FIFO8 retained objects and stale software aliases need an ownership proof. Candidate copies training payload into the FIFO so it need not retain a freed FTQ pointer. Query metadata and pipeline register widths/valid/epoch state remain unallocated.
4. History checkpoint storage and the970-bit directional GHR interface remain unresolved. A full-copy choice requires64×6354 Hint-history bits plus pending and live versions, but sharing/undo choices can differ; no universal minimum is claimed. The28-bit GHR fold and target's existing256-bit history do not remove recovery obligations.
5. A prediction block can contain32 two-byte instructions. Recovery scans at most32 retired controls and can additionally apply a corrected control. Choose prefix storage and restore/replay bandwidth, including ordering versus prediction; do not certify one-cycle recovery from a host loop.
6. Eight offered commit callbacks/cycle require a retirement interface from kmhv2, whose existing BPU update is one completed block. Queue admission, writer RMW, foreground query and readyCycle handling must share an explicit cycle schedule. Measurement-enable changes and idle catch-up must preserve modeled write epochs.
7. Specify finite preload/start/reset/control interfaces, canonical48-bit image address extension into50-bit target addresses, full64-bit query bounds and actual-target comparison, SRAM collision masks, macro overhead and required profile calibration.
